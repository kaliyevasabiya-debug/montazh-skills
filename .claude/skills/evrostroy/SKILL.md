# Еврострой — мой стиль рилсов

Монтаж кодом на Remotion, шаблон в `template/` (ролик «Еврострой — Black Friday», 2026-11-22, принят заказчиком; пример — `template/src/Evrostroy.tsx`). Пользователь не программист: пиши по-русски, коротко, код не показывай. **Перед рендером всегда присылай план + 2–4 кадра и жди «ок».** Не предлагай новых стилей — меняй только то, что просят, по одному примеру.

## ШРИФТЫ — ВСЕГДА ОДНИ И ТЕ ЖЕ, ВО ВСЕХ ВИДЕО
| Что | Шрифт | Файл | Цвет текста |
|---|---|---|---|
| **Заголовки** (крупно сверху), плашки товаров, цифры скидок | **Bebas Neue** (узкий капс), утолщение `WebkitTextStroke 2–3px` того же цвета | `template/public/fonts/Bebas.otf` (оригинал: `03_ресурсы/шрифты/BebasNeue Regular.otf`) | **белый `#FFFFFF`** с голубым свечением |
| **Обычный текст** (вторая строка под заголовком, субтитры) | **Montserrat Black** (700) / ExtraBold (600) | `template/public/fonts/MontBlack.ttf`, `MontXB.ttf` (оригинал: `03_ресурсы/шрифты/Montserrat-Black.ttf`) | **белый `#FFFFFF`**, акцентное слово — **красный `#D3141C`** с белой каймой |

Другие шрифты не брать, даже если «хочется разнообразия». Если нужен акцент — меняется только цвет (красный), не шрифт.

## ЦВЕТА — ВСЕГДА ОДНИ И ТЕ ЖЕ
- **Текст:** белый `#FFFFFF`. **Акцент (цены, главное слово):** красный `#D3141C` (в строке отделяется `|`: `"цены |не поднимали"`).
- **Плашка заголовка:** тёмно-синее «стекло» `linear-gradient(135deg, rgba(22,44,110,0.82), rgba(6,14,40,0.86))` + неоновая рамка `0 0 0 2px rgba(140,185,255,.95), 0 0 22px rgba(60,130,255,.85)`. Заголовок про цены («СКИДКИ РЕАЛЬНЫЕ», «УСПЕЙТЕ!») — та же плашка красная.
- **Вторая строка:** без плашки, белая с мягкой тенью, одно слово красное.
- **Субтитры:** белые, ключевое слово белым на тёмно-синей плашке с неоновой рамкой.
- **Скидки (−20%…):** тёмно-красный градиент `#E8333C → #C4121B → #8E0A10` + белая кайма 2–3px + светлое свечение. Без тёмного пятна, без чёрных теней (`DISC = "E"`).
- **Размеры (одинаковые везде):** заголовок 120, вторая строка 62, плашка товара 110, скидка 380, субтитры 56.
- **Лут:** Portra 400 (`03_ресурсы/луты/Portra 400.cube`) на 55% — только снятые кадры, не интро с нейросетью и не графика.

## ЗВУКИ
Из `02_звук/норм_звуки` (копии в `template/public/sfx2`, пики и громкость — `template/src/sfx2.json`). Средняя громкость, не на каждое слово:
- перечисление (товары) — **один и тот же** звук на каждый пункт: `bubbly`;
- скидки / новые цены — один звук на все: `ding`; самая большая скидка — другой, но мягкий: `tings` (лёгкий «тинь»). **«Кассу» (`cash`) не ставить** — пользователь попросил убрать;
- смена сцены — `fast` / `wh2`; слово «вниз» — `sword3`; акцентные слова — разные мягкие попы (`jug1`, `uipop`, `pop4`, `popclick`); «реальные/успех» — `success`; «Успейте!» — `buy` (оплата iPhone).
- Удары/райзеры из PROXIMA не брать — бьют по ушам.

## Шаги
1. **Исходник** → `01_исходники/`. В облаке: Google Drive — `gdown <id>` (флага `--fuzzy` в этой версии нет), Яндекс Диск — API `cloud-api.yandex.net/v1/disk/public/resources/download?public_key=<ссылка>`. Instagram по ссылке не открывается (429) — просить запись экрана.
2. **Проект:** скопируй `template/` в `work/<тема>/`, `npm install`, видео → `public/media/v1.mp4` (`ffmpeg -r 30 -c:v libx264 -crf 16 -pix_fmt yuv420p -c:a aac 192k`).
3. **Разметка:**
   - речь: faster-whisper `medium` на CPU, аудио передавать массивом (`soundfile`), иначе ошибка `metadata_errors`;
   - смены кадров: `ffmpeg -vf "select='gt(scene,0.25)',showinfo"`; кадр из середины каждого — лист, чтобы понять, **какой товар на каком кадре**;
   - где лицо в каждой сцене (текст не на лицо).
4. **План** таблицей «секунда → что на экране → звук» + 2–4 кадра (`node render.mjs stills Evrostroy 12 16 22 35`). Ждать «ок».
5. **Код:** копия `src/Evrostroy.tsx`: `W` (субтитры), заголовки `BTitle`/`BLine`, `Tag` (товары), `Fire` (скидки), `SFX`.
6. **Проверка:** кадры с рамкой безопасной зоны (drawbox `y 400–1560`, `x 100–980`), одинаковые размеры, нет дублей.
7. **Лут:** перед финальным рендером прогнать `public/media/v1.mp4` и вырезки `public/cut1/*.webp` через `lut3d` + `blend 55%` с `enable='gte(t,<конец интро>)'` (для webp — `format=rgba`, прозрачность сохраняется). Оригиналы держать в `v1_orig.mp4` / `cut1_orig`.
8. **Рендер:** `node render.mjs full Evrostroy` (≈ 6–8 мин на 42 с). Кусок для проверки звука: `node render.mjs part Evrostroy 9.7 26`.
9. **Финал:** звук начала (интро с нейросетью) **подставить из исходника один в один**, дальше — звук рендера, **без loudnorm на весь ролик**:
   `[исходник]atrim=0:T,afade=out` + `[рендер]atrim=T` → `concat` → `04_рендер/<тема>/<дата>_<тема>_<вариант>.mp4`, < 90 МБ. Проверить `volumedetect`: громкость интро = исходнику.

## Правила (выучены на ошибках)
- **Картинку не затемнять сильно** — заказчик любит ярко. Затемнение сверху/снизу максимум 0.1–0.15, без виньетки.
- **Субтитры не дублируют заголовки.** Если фраза написана сверху — внизу её нет. Субтитры только там, где сверху пусто. Одна фраза — одно место.
- **Две синие плашки подряд нельзя.** Плашка только у заголовка; вторая строка — белая, акцент красным.
- **Подпись товара держится на всех кадрах этого товара** (общий + крупный план), ставится по картинке, а не по слову. Если голос обгоняет картинку — по картинке.
- **Одинаковые размеры** у всех заголовков / строк / плашек / цифр; всё в зоне Reels: сверху ≥ 400 px, снизу ≤ 1560 px, по бокам ≥ 100 px.
- **Наложения пользователя** не выкидывать: толпа «Black Friday» — смысловая, показывать чётко (без размытия/зума); только убрать белёсую дымку снизу и вырезать человека (`scripts/cutout.py`, rembg `u2net_human_seg`, ставить `pip install rembg onnxruntime`). Двери на красной сетке → две панели в рамках со свечением на размытом фоне.
- **Начало, сделанное нейросетью, не трогать:** ни звуки поверх, ни цвет, ни громкость.
- **Звуки:** приятные, средней громкости (пики около −22…−25 dB), не на каждое слово, без одного и того же «вжуха» подряд (кроме перечисления и скидок — там намеренно одинаковые).
- **Не понравилось пользователю (не предлагать):** оранжевый «огонь», журнальный тёмный стиль с тонкими шрифтами, ровные плоские блоки, красная плашка-ценник, круглый стикер, красная цифра с толстой обводкой и синей 3D-тенью, белая цифра с красной полоской, стопки слов «как в примере» с кругом в финале.
- **Музыка:** «до минуты можно» — миф. Для рекламы — только лицензированная (Meta Sound Collection в Instagram, Pixabay Music, Epidemic Sound на коммерческом тарифе). Музыку класть под речь, интро оставить с родным звуком.

## Облако (особенности)
- Рендер Remotion: в `render.mjs` уже стоит `browserExecutable: /opt/pw-browsers/chromium_headless_shell`, `gl: swangle`.
- Не запускать два рендера одновременно; при остановке — `pkill -f "render.mjs full"; pkill -f chrome-headless-shell`.
- Файлы > 50 МБ GitHub предупреждает, > 100 МБ не примет — держать < 90 МБ.
