# Еврострой — монтаж рилсов

Монтаж кодом на Remotion. Шаблон `template/` с тремя принятыми заказчиком роликами:
- `src/Evrostroy_ru.tsx` — **русский, 2026-11-23** (быстрый: 10 товаров за 58 с) — **брать за основу**;
- `src/Evrostroy_kz.tsx` — **казахский, 2026-11-23** (75 с, 10 товаров);
- `src/Evrostroy.tsx` — старый Black Friday 2026-11-22 (наложения толпы/дверей, интро с нейросетью).

Пользователь не программист: по-русски, коротко, код не показывать. Пользователь торопится: **один пример за раз**, не плодить варианты. Перед рендером — план + 2–4 кадра (кадры с рамкой зоны Reels проверь сам). Если меняется только начало — можно отдать только кусок (`node render.mjs part <ID> 0 <конец кадра>`).

## ШРИФТЫ — ВСЕГДА ОДНИ И ТЕ ЖЕ (русский и казахский)
| Что | Шрифт | Размер | Цвет | Наклон |
|---|---|---|---|---|
| Заголовок на плашке (`BTitle`) | **Oswald** 700, капс (`public/fonts/Oswald.ttf`, семейство `Head`) | 104 | белый с голубым свечением; про цены/город — красная плашка | **ровно** |
| Название товара (`Tag`) | Oswald 700, капс | 80 | белый, синяя неоновая плашка | **−2°** |
| Обычный текст / вторая строка (`BLine`) | **Montserrat Black** (`MontBlack.ttf`) | 72 | белый, акцент **красный `#D3141C`** с белой каймой | **ровно** |
| Старая цена (`OldPrice`) | Montserrat Black | 58 | белая, зачёркнута красной линией; справа красная плашка «−22%» | ровно |
| Новая цена (`Price3D`) | Oswald 700 | 180 | **объёмная 3D**: лицо красный градиент с бликом, белая кайма, толщина 18 слоёв от `#C3141C` до `#280306`, наклон perspective rotateX 14° | — |
| Субтитры | Montserrat Black | 56 | белые, ключевое слово белым на синей неоновой плашке | ровно |

- **Bebas Neue не использовать** — в нём нет казахских букв (Қ Ұ Ң І Ә Ғ Ө Ү Һ). Oswald есть и для русского, и для казахского.
- Акцент в строке: `|` переключает белый/красный: `"|Еврострой| құрылыс маркеті"`, `"кешкі |17:00 – 22:00"`.
- **В каждой строке должно быть красное ключевое слово** (город, бренд, время, дата, «не поднимали» и т.п.).
- Цена — **только значок ₸**: не писать «теңге», «тенге», «-ден».

## ЦВЕТА
- Синяя плашка: `linear-gradient(135deg, rgba(22,44,110,0.82), rgba(6,14,40,0.86))` + неоновая рамка `0 0 0 2px rgba(140,185,255,.95), 0 0 22px rgba(60,130,255,.85)`.
- Красная плашка: `linear-gradient(135deg, rgba(200,20,30,0.9), rgba(110,6,14,0.9))` + красное свечение.
- Акцент: `#D3141C`. Картинку **не затемнять** (максимум лёгкая тень 0.1–0.15 сверху/снизу), без виньетки.
- Лут Portra 400 на 55% — **по запросу**; обычно сначала отдать без лута.

## РАСКЛАДКА (одинаково у всех товаров)
- **Блок товара внизу, ниже подбородка:** название `y 1180`, старая цена + процент `y 1270`, 3D-цена `top 1405`. Всё в зоне Reels: сверху ≥ 400, снизу ≤ 1556, по бокам ≥ 100.
- **Исключение — лицо внизу** (ведущий лежит/сидит на полу): весь блок поднять **над головой** (ковры: 470 / 560 / 690), с отступом от головы ≥ 150 px.
- Заголовки сверху: `top 400–410`, строка под ним `538–585` — **только если макушка ниже ~650 px**. Если голова высоко (у верхнего края) — заголовки **под лицом** (`top 1015`, строка `1170`). Поднять над головой при макушке ~400 нельзя: закроет интерфейс Instagram — так и объяснить.
- **Текст никогда не на лице и не впритык к лицу** (отступ ≥ ~100–150 px). Перед рендером прогнать проверку лиц (OpenCV `haarcascade_frontalface_default`, каждые 0.2–0.25 с, по каждому кадру товара: макушка ≈ верх лица − 45% высоты, низ ≈ подбородок + 30 px) и посмотреть кадры глазами — у haar бывают ложные «лица» (руки).
- Подпись товара держится **на всех кадрах этого товара** (по картинке, не по слову).
- Субтитры — только там, где сверху нет заголовка; не дублировать.

## СТРУКТУРА РОЛИКА
1. **Начало:** красная плашка с **городом** («АКТОБЕ» / «АҚТӨБЕ») + строка «**27 ноября**» → строка «**Еврострой** · …» → красная плашка «ЧЁРНАЯ ПЯТНИЦА» / «ЖҰМА ЖЕҢІЛДІКТЕРІ» + «кешкі **17:00 – 22:00**». Синюю плашку под красной не ставить (пользователю не понравилось).
2. **Товары:** `Tag` + `OldPrice` (с `pct`) + `Price3D`. Новая цена **влетает сверху вниз** со «вжухом», прокрутка от старой к новой **0.25 с** (в быстрых роликах иначе итоговую цену не успеть прочитать).
3. **Финал:** субтитр «Обычно **Еврострой** работает до **18:30**» → «27 НОЯБРЯ» + «работаем до **22:00**» → красная «СПЕЦИАЛЬНЫЕ ЦЕНЫ» / «АРНАЙЫ ЖЕҢІЛДІКТЕР» + «**с 17:00 до 22:00**».

## ЦЕНЫ — ПО ФАКТУ
- Распознавание путает цифры (особенно казахское) — **таблицу цен «было → скидка → стало» показать пользователю** и отметить, в чём не уверен.
- Ведущий часто **округляет устно** («стал 30», «за 139») — на экране писать **точную** цену = старая × (1 − скидка): 76 000 −60% → **30 400 ₸**, 185 000 −25% → **138 750 ₸**.
- Процент показывать у всех товаров (одно место — рядом со старой ценой). Если цена «от» (ламинат) без старой — без процента.

## КАМЕРА («дорогой» монтаж, без тряски)
- `CamFX`: на каждом кадре плавный наезд/отъезд по очереди (1→1.06 / 1.06→1), в финале мягко 1→1.035.
- На склейках внутри кадра (вырезанный фальстарт) — смена крупности ×1.07.
- Акцент-зум +3.5% на каждой новой цене и на ключевой фразе финала («сіздер үшін» / «специально для вас»).
- **Масштаб всегда ≥ 1** — никогда не уменьшать кадр (видны края — пользователю не понравилось).

## ЗВУКИ (`public/sfx2`, громкость по `src/sfx2.json`, средняя)
- товар (перечисление) — один и тот же `bubbly`; старая цена — `glassy`; новая цена — `wshort` (вжух) + `ding`;
- самая большая скидка — `tings` (мягкий). **«Кассу» (`cash`) не ставить.**
- заголовки — `pop4` / `jug1` / `uipop`, красная «скидочная» плашка — `success`, смена сцены — `fast`, последняя фраза — `buy`.
- Удары/райзеры не брать — бьют по ушам.

## РЕЧЬ И ТЕМП
- **Темп ведущего не трогать:** паузы не вырезать (иначе «скороговорка»). Вырезать **только явные фальстарты/повторы** (искать по звуку: короткий звук между двумя паузами в середине фразы).
- Распознавание: faster-whisper `large-v3` на CPU (~5 мин на 75 с), `language="ru"` или `"kk"`, аудио массивом через `soundfile`; без `initial_prompt` (с ним галлюцинирует).

## Шаги
1. Исходник → `01_исходники/` (`gdown <id>`; Яндекс Диск — через API public download).
2. `work/<тема>/`: видео → `src.mp4` (30 fps), распознать слова, найти смены кадров (`select='gt(scene,0.3)'`), проверка лиц по кадрам.
3. Проект: скопировать `template/`, `npm install` (или ссылка на готовый `node_modules`), видео в `public/media/v1.mp4`, копия `src/Evrostroy_ru.tsx` → заменить `SHOTS`, `PUNCH`, тексты, `P` (товары) и `SFX`.
4. Кадры (`node render.mjs stills <ID> …`) с рамкой зоны Reels → план + таблица цен пользователю.
5. `node render.mjs full <ID>` (~8 мин на 58 с; два рендера одновременно не запускать — при остановке `pkill -f "render.mjs full"; pkill -f chrome-headless-shell`, затем **заново скопировать `v1.mp4`**, он мог повредиться).
6. Перекодировать в `04_рендер/еврострой/<дата>_еврострой_<тема>_<язык>.mp4` (crf 19, aac 192k), проверить `volumedetect` = исходник, закоммитить, запушить.

Бегущая лента сверху; цена «за человеком» с вырезанием ведущего; отъезд камеры с видимыми краями; синяя плашка под красной в начале; оранжевый «огонь»; тёмный журнальный стиль; плоские блоки; красный ценник/круглый стикер; цифра с толстой обводкой и синей 3D-тенью; белая цифра с красной полоской; «касса»; ускорение речи; сильное затемнение.
