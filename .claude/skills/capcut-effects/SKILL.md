# Эффекты для CapCut

Видео уже смонтировано и покрашено в CapCut. Скилл рисует эффекты кодом (HTML → прозрачные видео ProRes 4444) и вставляет их в проект отдельными дорожками **над** корректирующими слоями, чтобы LUT их не перекрашивал. Исходные клипы и цветокор не трогаются, перед каждой вставкой делается полный бэкап проекта.

Пользователь, скорее всего, не программист. Объясняй простыми словами, код не показывай. После каждого этапа: «что сделал» и «что проверить». Сначала показывай кадры, вставляй только после «да».

## Первый запуск (один раз)
1. Скопируй `template/` в папку проекта. Нужны Node.js 20+, ffmpeg 7+, Google Chrome, Python 3.10–3.12. `npm install`.
2. Распознавание речи: `.venv` с `faster-whisper numpy` (модель large-v3-turbo скачается сама, ~1.6 ГБ). Для русского без интернета подойдёт и `scripts/transcribe.py` (sherpa-onnx, как в скилле clean-cut).
3. **Шрифты.** Стиль на Gotham и Helvetica Neue — они платные, в скилл не входят. Если они установлены в Windows/macOS — подхватятся сами (или положи файлы в `a/fonts/`). Если нет — автоматически будут бесплатные Montserrat и Inter (лежат в `a/`). Платные шрифты никуда не выкладывай.

## Как делать
1. **Найди проект CapCut.** Windows: `%LOCALAPPDATA%\CapCut\User Data\Projects\com.lveditor.draft\<имя>\draft_content.json`, Mac: `~/Movies/CapCut/User Data/Projects/com.lveditor.draft/<имя>`. Имя проекта — в `draft_meta_info.json` (`draft_name`); папки иногда переименовывают — ищи по имени. Файл `.locked` = проект открыт.
2. **Разбери монтаж.** В `draft_content.json`: размер кадра (`canvas_config`), куски главной видеодорожки (`source_timerange` — откуда из исходника, `target_timerange` — куда на таймлайне), корректирующие слои (`adjust`), LUT в `materials.effects`.
3. **Подложка для превью.** Собери из исходника те же куски в `media/cut.mp4` (1920×1080, 30 к/с) с тем же LUT (`lut3d`), чтобы кадры выглядели как в CapCut. В проект она не идёт.
4. **Слова.** Звук тех же кусков → `.venv/Scripts/python scripts/words.py work/voice.wav work/words.txt` (язык определится сам). Казахский и имена распознаются с ошибками — **спроси точный текст** спорных фраз.
5. **Вопросы и план.** Спроси: язык надписей, какие скрины есть (чат с Claude, таймлайн, комментарии Instagram — только свои, без чужих личных данных без разрешения), цифры (расходы, суммы), где можно закрыть спикера полноэкранной вставкой. Покажи таблицу «время → что звучит → эффект» и дождись «ок».
6. **Сцены** в `video.html` (там готовый пример — 7 сцен, меняй тексты, времена, картинки). Время сцены `data-s/data-e` — секунды таймлайна CapCut; все времена внутри — от начала сцены. Каждая сцена с `data-piece="NN_имя"` станет отдельным клипом. `data-kind="full"` — полноэкранная непрозрачная вставка, без него — графика поверх спикера (справа, `.shade` слегка затемняет край).
7. **Кадры.** `node render.mjs stills 2 11 24 ...` → `work/still_*.jpg`: смотри сам (ничего не вылезает за край, текст не на лице, всё читается), потом лист кадров пользователю.
8. **Рендер.** `node render_pieces.mjs "<папка эффектов>"` → `NN_имя.mov` (прозрачные), `sfx.wav` (все звуки одной дорожкой с 0:00), `pieces.json`. Если Chrome упал — запусти снова, готовые куски пропускаются. Собери превью: подложка + куски + звуки → `превью.mp4`, покажи.
9. **Вставка** (CapCut закрыт!): `python patch_capcut.py "<папка проекта>" "<папка эффектов>" "<куда бэкап>"`. Скрипт делает бэкап, заменяет дорожки «Эффекты A/B» и «Звуки эффектов», режет звук ровно по концу ролика.
10. **Правка одного куска**, когда пользователь уже двигал клипы в CapCut: перерисуй только его — `ONLY=03_montage SUFFIX=_v2 node render_pieces.mjs "<папка>"` — и поменяй в `draft_content.json` путь только у этого материала (бэкап перед этим). Полную вставку заново не делай — она сотрёт его раскладку и переходы.

## Элементы (v3.css)
| Элемент | Что это |
|---|---|
| `.rt` + `span[data-in]` | Крупный текст справа, Gotham Black капсом; `.pk` — розовый, остальное белое |
| `.v-bg` (`.warm`) + `svg.chart` | Тёмный фон и качающийся график (рисуется в `onFrame`) |
| `.tbl` / `.tr` + `data-miss` | Таблица слева: значок, название, подпись, статус; строка тускнеет после «пропустил» |
| `.rblk` | Крупная фраза справа на полноэкранной вставке, сменяется по словам |
| `.mid` | Главный элемент по центру (звезда Claude + слово + розовая подпись) |
| `.fw` + `data-tilt` | Окно-скрин без рамки, с наклоном в 3D (настоящие скрины из `media/ref/`) |
| `.chip` | Плашка «Claude Code монтаж жасап жатыр…» |
| `.bign` + `.grid` + `.card` + `.tg` | «20+» и сетка переключателей iPhone; включаются по очереди, выключаются волной |
| `.cic` + `.mn.sat` + `.ringo` | Орбита: значок Claude и мини-окна с настоящим содержимым (таблица, дорожки, схема) |
| `.old` / `.new` / `.months` | Зачёркнутая сумма → новая сумма, линия по месяцам до текущего |
| `.ibox` + `.bub` + `.step` | Поле ввода Claude (Bypass permissions, Opus), промпты печатаются и уходят пузырями |

Анимации: `data-in`, `data-out`, `data-from`, `data-pop`, `data-dist`, `data-dur`, `data-drift`, `data-tilt`, `data-count`, `data-type`; звук `data-sfx="whoosh|pop|hit|click|ding|tick|thud"` и `data-vol`. Свои движения — в `window.onFrame(t)`.

## Правила
- Только эффекты: нарезку и цвет не трогать.
- Одна мысль — один элемент; всё появляется на своём слове.
- На экранах — настоящая информация (цифры, пункты, команды), не пустые плашки. Не выдумывай факты; примерные цифры помечай и согласуй.
- Белый + один акцент (розовый `#ff7eb6`); Gotham для крупного текста, Helvetica для мелкого.
- Ничего важного не закрывает лицо; тексты не вылезают за край кадра.
- Чужие ролики не копируем — берём приём. Платные шрифты и чужие личные данные не публикуем.

## Частые проблемы
- **«Проект открыт в CapCut»** — закрой CapCut полностью.
- **Клипы красные в CapCut** — файлы эффектов перенесли; верни папку или вставь заново.
- **Эффекты перекрашены** — дорожки оказались под корректирующим слоем: подними их выше.
- **В CapCut старая версия куска** — CapCut держит прокси: новый файл всегда с новым именем (`SUFFIX`).
- **Буквы другим шрифтом** — нет Gotham/Helvetica: всё в порядке, это Montserrat/Inter.
