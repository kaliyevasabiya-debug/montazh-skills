# montazh-skills — монтаж с телефона через Claude Code

## Структура папок для монтажа рилсов

| Папка | Что класть | Примеры |
|---|---|---|
| `01_исходники/` | Сырое видео с камеры и телефона, как есть, без обработки | `2026-11-22_дубль1.mp4`, `съёмка_кафе_общий.mov` |
| `02_звук/` | Озвучка, музыка, звуковые эффекты | `голос_важность.mp3`, `музыка_пианино.mp3`, `вжух.wav` |
| `03_ресурсы/` | Всё, что вставляется в ролик поверх видео | разложено по подпапкам ниже |
| `03_ресурсы/шрифты/` | Шрифты (`.ttf`, `.otf`) | `Montserrat-Bold.ttf` |
| `03_ресурсы/картинки/` | Фото, скрины, логотипы, фоны (`.png`, `.jpg`) | `лого.png`, `скрин_отзыв1.jpg` |
| `03_ресурсы/видео/` | Чужие и готовые вставки: B-roll, футажи, примеры | `broll_город.mp4` |
| `03_ресурсы/иконки/` | Иконки и стикеры | `сердце.png` |
| `04_рендер/` | Только готовые ролики, которые можно выкладывать | `2026-11-22_важность_v2.mp4` |

### Правила
1. **Исходники не трогаем.** В `01_исходники` лежат оригиналы. Не обрезаем, не переименовываем после начала монтажа и не удаляем, пока ролик не вышел.
2. **Имена файлов:** `дата_тема_что.расширение`, без пробелов: `2026-11-22_важность_голос.mp3`. Версии — `_v1`, `_v2`, а не «финал_точно_финал».
3. **Одна тема — одна подпапка**, если роликов много: `01_исходники/важность/`, `02_звук/важность/`.
4. **В `04_рендер` — только готовое.** Черновики и пробы туда не кладём, их Claude держит в `work/`.
5. **Размер.** Файлы больше 90 МБ GitHub не принимает. Исходники поэтому в GitHub не отправляются (папка `01_исходники` в `.gitignore`), а готовые ролики Claude пережимает до 90 МБ.
6. **Музыка и чужие видео — только с правом на использование** (своя, бесплатная библиотека или купленная лицензия). Ссылку на источник положите рядом в `.txt` с тем же именем.

---

Скиллы для монтажа, которые работают в облаке Claude Code. Монтируешь с телефона: даёшь ссылку на видео и пишешь, каким скиллом.

## Настройка (один раз, на ноутбуке, ~15 минут)

1. **GitHub.** Зарегистрируйся на github.com → «New repository» → имя `montazh-skills` → **Private** → Create.
2. **Загрузи эту папку.** Проще всего через программу **GitHub Desktop** (desktop.github.com): File → Add local repository → выбери эту папку → Publish repository (галочка «Keep this code private»).
   Через сайт тоже можно («uploading an existing file»), но сайт берёт максимум 100 файлов за раз, а их тут больше 400 — неудобно.
3. **Подключи GitHub к Claude.** Открой claude.ai/code → подключи GitHub → дай доступ к репозиторию `montazh-skills`.
4. **Окружение.** В claude.ai/code создай окружение (environment), например «Монтаж»:
   - **Network access / Доступ в сеть:** Full (полный). Иначе не скачается видео с Google Drive, Chrome и модели распознавания.
   - **Setup script / Скрипт установки:** вставь целиком содержимое файла `setup.sh`.

## Каждый раз, с телефона

1. Залей исходник в Google Drive → «Поделиться» → «Все, у кого есть ссылка» → скопируй ссылку.
2. Приложение Claude → вкладка **Code** → новая сессия → выбери окружение «Монтаж» и репозиторий `montazh-skills`.
3. Напиши, например:
   `<ссылка> Смонтируй это видео используя скилл /nurserik-studio-hook`
4. Когда Claude закончит — открой репозиторий на GitHub → ветку, которую он назвал → папка `04_рендер` → скачай mp4.

## Какие скиллы здесь есть

| Скилл | Что делает |
|---|---|
| `nurserik-studio-hook` | таргет-креатив / рилс 9:16 с говорящей головой |
| `nurs-shym-trip` | рилс «эксперт объясняет приём», как Ержан: жёлтый капс + рукописная подводка, слова за головой, B-roll, ДО/ПОСЛЕ. С телефона давай уже нарезанное видео (нарезка внутри CapCut — только на ноутбуке) |
| `editorial-motion` | редакционный моушн к рилсу (синие узкие заголовки, кнопки, частицы) |
| `clean-cut` | черновой монтаж: вырезает паузы и дубли, субтитры |
| `reels-motion-titles` | рилс с моушн-титрами |
| `expert-split` | эксперт снизу, схема сверху |
| `room-windows` | горизонтальный YouTube 16:9 с окнами рядом со спикером |
| `clean-premium` | ролик без лица голосом за кадром |
| `motion-graphic` | неоновая графика 16:10 для экрана ноутбука |
| `red-collage`, `paper-history` | ролики-коллажи голосом за кадром |
| `cartoon-3d`, `cartoon-3d-short` | 3D-мультики |
| `yt-*` | сценарии, названия, описания, план, разбор канала — без монтажа |

**Не вошли:** `capcut-effects` и `yt-claude-montage` (им нужен CapCut на компьютере), `shorts` (730 МБ и настроен под Windows).

## Ограничения
- Видеокарты в облаке нет — распознавание и рендер медленнее, чем на хорошем ноутбуке.
- Готовое видео должно быть меньше 100 МБ (лимит GitHub) — Claude сам пережимает до 90 МБ.
- Каждая новая сессия заново ставит программы из `setup.sh` — первые минуты уходят на это.
- `setup.sh` при каждом запуске скачивает свежие скиллы из этого репозитория — новые скиллы приходят сами, «Sync fork» не нужен.
